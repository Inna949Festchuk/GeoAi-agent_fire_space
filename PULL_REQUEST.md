Чтобы работать вместе с товарищем, лучшим решением будет сделать форк (Fork), а затем его клон.
Если ваш товарищ не добавил вас в репозиторий как «коллаборатора» (Collaborator) с правами прямой записи, вы не сможете пушить код напрямую в его репозиторий. Форк решает эту проблему.
Ниже пошаговый и простой алгоритм, как это сделать.
------------------------------
## Шаг 1. Создание форка и клонирование

   1. Сделайте Форк: Зайдите на страницу репозитория вашего товарища на GitHub и в правом верхнем углу нажмите кнопку Fork. Это создаст точную копию его проекта, но уже в вашем личном GitHub-аккаунте.
   2. Склонируйте свой форк: Откройте ваш созданный форк на GitHub, скопируйте ссылку и склонируйте его себе на компьютер (или хост) через терминал:
   
   git clone <ссылка_на_ВАШ_форк>
   
   3. Свяжитесь с оригиналом (необязательно, но полезно): Чтобы в будущем скачивать обновления, которые делает ваш товарищ, добавьте ссылку на его оригинальный репозиторий под именем upstream:
   
   cd <имя_папки_проекта>
   git remote add upstream <ссылка_на_оригинальный_репозиторий_товарища>
   
   
------------------------------
## Шаг 2. Внесение изменений
В Git считается хорошим тоном не работать в ветке main (или master), а создавать для каждой новой задачи отдельную ветку.

   1. Создайте новую ветку:
   
   git checkout -b my-feature-branch
   
   2. Сделайте изменения: Отредактируйте или добавьте нужные файлы.
   3. Закоммитьте изменения:
   
   git add .
   git commit -m "Добавил новые функции"
   
   4. Отправьте (push) код в свой GitHub:
   
   git push origin my-feature-branch
   
   
------------------------------
## Шаг 3. Как запросить вытягивание (Создать Pull Request)
После того как вы выполнили git push, ваши изменения появились в вашем форке на GitHub. Теперь нужно попросить товарища забрать их в оригинальный проект.

   1. Зайдите на сайт GitHub в свой аккаунт и откройте ваш форк.
   2. Вверху страницы появится желтая плашка с уведомлением о том, что вы только что отправили новую ветку. Нажмите на ней зеленую кнопку «Compare & pull request» (Сравнить и создать пул-реквест).
   * Если плашки нет: перейдите на вкладку Pull Requests и нажмите зеленую кнопку New pull request.
   3. Убедитесь, что GitHub правильно настроил направление стрелки:
   * base repository: оригинальный репозиторий товарища (main) ◄— head repository: ваш форк (my-feature-branch).
   4. Напишите понятное название для PR и короткое описание (что именно вы изменили).
   5. Нажмите кнопку «Create pull request».

Что произойдет дальше: Ваш друг получит уведомление на GitHub. Он увидит все ваши изменения, сможет их протестировать, обсудить с вами в комментариях и, если всё отлично, нажмет кнопку Merge, после чего ваш код окажется в его основном проекте.
------------------------------
Если хотите, мы можем разобрать детали. Подскажите:

* Вы будете работать через терминал или используете какую-то программу (например, VS Code, GitKraken)?
* Нужна ли помощь с командами для синхронизации вашего форка с новыми коммитами товарища, если он успеет что-то обновить?


Чтобы ваш код не устаревал, вам нужно периодически скачивать изменения из оригинального репозитория товарища.
Если на Шаге 1 вы уже добавили оригинальный репозиторий как upstream (командой git remote add upstream ...), то процесс обновления займет всего пару шагов. Если вы этого еще не сделали, сначала выполните привязку.
Вот как правильно обновлять свой локальный код и свой форк на GitHub:
------------------------------
## Способ 1. Через терминал (Самый надежный)
Выполняйте эти команды каждый раз перед тем, как начать писать новый код.
1. Переключитесь на основную ветку у себя на компьютере:

git checkout main

(Или master, в зависимости от того, как называется главная ветка в проекте).
2. Скачайте изменения из репозитория товарища (upstream):

git fetch upstream

3. Слейте изменения товарища в свою локальную ветку:

git merge upstream/main

Теперь на вашем компьютере самая свежая версия кода.
4. Обновите свой форк на GitHub (чтобы там тоже всё было актуально):

git push origin main

------------------------------
## Способ 2. Через интерфейс GitHub (В один клик)
Если вы не хотите вводить команды в терминале, GitHub умеет обновлять ваш форк автоматически.

   1. Зайдите на сайт GitHub на страницу вашего форка.
   2. Под зеленой кнопкой <> Code вы увидите строчку: «This branch is X commits behind [репозиторий_товарища]:main».
   3. Справа от этой надписи нажмите кнопку Sync fork (Синхронизировать форк).
   4. В выпадающем меню нажмите Update branch.

⚠️ Важно: После того как вы обновили форк на сайте GitHub, изменения нужно скачать к себе на компьютер. Для этого в терминале выполните:

git checkout main
git pull origin main

------------------------------
## 💡 Полезный совет: Как обновить свою рабочую ветку (my-feature-branch)?
Если вы уже пишете код в своей отдельной ветке, а товарищ в этот момент выложил что-то важное в оригинал, обновите сначала ветку main (как написано в Способе 1), а затем перейдите в свою рабочую ветку и «вберите» в неё новые изменения:

git checkout my-feature-branch
git merge main

Если возникнут конфликты (вы правили одну и ту же строчку кода), Git попросит вас их исправить, после чего вы сможете продолжить работу.
