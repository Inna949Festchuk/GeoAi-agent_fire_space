# Fire Monitor - AI-powered Wildfire Monitoring System

Система мониторинга лесных пожаров на основе спутниковых данных с AI-агентом для анализа и визуализации.

## 🚀 Возможности

### Основные функции
- **Поиск активных пожаров** - мониторинг термальных аномалий со спутников VIIRS и MODIS
- **Анализ гарей** - картографирование выгоревших территорий с помощью Sentinel-2
- **AI-агент** - интеллектуальный помощник для анализа данных и построения маршрутов
- **Визуализация** - интерактивная карта с попапами и статистикой

### AI-инструменты

#### Поиск и анализ
- `search_fires` - поиск активных очагов пожаров по bbox
- `get_fire_statistics` - статистика пожаров по региону
- `search_sentinel2_scenes` - поиск спутниковых сцен Sentinel-2
- `map_burn_area` - картографирование гарей (dNBR анализ)
- `generate_burn_report` - генерация аналитических отчётов

#### Маршрутизация и геолокация
- `build_route` - построение маршрута между двумя точками через OSRM
- `build_routes_batch` - пакетное построение нескольких маршрутов
- `find_nearest_fire_stations` - поиск ближайших пожарных частей через Overpass API

#### Выполнение кода
- `execute_python` - выполнение Python-кода в изолированной песочнице для геоаналитики
  - Доступные библиотеки: numpy, pandas, geopandas, shapely
  - Безопасная изоляция: без сетевого доступа, с лимитами ресурсов
  - Визуализация результатов на карте через `__result__`

## 🛠️ Технологии

### Backend
- **Django 5.1** + Django REST Framework
- **PostgreSQL 16** + PostGIS 3.4
- **GDAL/GEOS/PROJ** - геопространственные библиотеки
- **OpenAI API** (Qwen модель) - AI-агент

### Frontend
- **React 18** + Vite
- **MapLibre GL JS** - интерактивная карта
- **Recharts** - визуализация данных

### Инфраструктура
- **Docker** + Docker Compose
- **FastMCP** - MCP-сервер для внешних агентов
- **FastAPI** - sandbox для выполнения кода

## 📦 Установка и запуск

### Требования
- Docker и Docker Compose
- API ключ NASA FIRMS (получить на https://firms.modaps.eosdis.nasa.gov/api/)
- API ключ для LLM (например, через routerai.ru)

### Быстрый старт

1. **Клонировать репозиторий**
```bash
git clone <repository-url>
cd fire-monitor
```

2. **Настроить переменные окружения**
```bash
cp .env.example .env
# Отредактировать .env и добавить API ключи
```

3. **Запустить в dev-режиме**
```bash
docker compose -f docker-compose.dev.yml up -d --build
```

4. **Открыть в браузере**
- Frontend: http://localhost:5173
- Backend API: http://localhost:8000/api/
- MCP Server: http://localhost:8001/mcp
- Sandbox: http://localhost:8002

### Production запуск
```bash
docker compose up -d --build
```

## 🔌 MCP интеграция

MCP-сервер предоставляет 9 инструментов для внешних AI-агентов:

### Подключение
```json
{
  "mcpServers": {
    "fire-monitor": {
      "type": "sse",
      "url": "http://localhost:8001/mcp"
    }
  }
}
```

### Доступные инструменты

1. **search_fires** - поиск активных пожаров
2. **search_sentinel2** - поиск спутниковых сцен
3. **get_fire_stats** - статистика пожаров
4. **get_burn_stats** - статистика гарей
5. **start_fire_detection** - запуск детекции пожаров
6. **start_burn_mapping** - запуск картографирования гарей
7. **build_route_mcp** - построение маршрута
8. **find_nearest_fire_stations_mcp** - поиск пожарных частей
9. **execute_python_mcp** - выполнение Python-кода

## 🔒 Безопасность

### Sandbox
- **AST-фильтрация** - блокировка опасных конструкций (`os`, `subprocess`, `eval`, `exec`)
- **Изоляция сети** - `network_mode: none` в Docker
- **Лимиты ресурсов** - CPU, RAM, время выполнения
- **Read-only файловая система** - `read_only: true`
- **Непривилегированный пользователь** - `sandbox_user`

### Overpass API
- Fallback на несколько серверов (Франция, Германия, Швейцария, Россия)
- Rate limiting для защиты от злоупотреблений

## 🐛 Troubleshooting

### Overpass API не отвечает
Система автоматически переключается на резервные серверы:
1. overpass.openstreetmap.fr (Франция) - основной
2. overpass-api.de (Германия)
3. overpass.osm.ch (Швейцария)
4. overpass.openstreetmap.ru (Россия)

### Sandbox не запускается
```bash
docker logs fire-monitor-sandbox
# Проверить наличие системных библиотек: libgeos-dev, libproj-dev, gdal-bin
```

### Маршруты не строятся
- Проверить доступ к интернету из backend контейнера
- OSRM сервер: router.project-osrm.org
