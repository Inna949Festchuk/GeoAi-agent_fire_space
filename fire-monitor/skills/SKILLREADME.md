## 📋 Что делает этот скилл (кратко)

**`fire_monitor_validation_pipeline`** — это автономный пайплайн валидации системы «Стрела», который:

| Этап | Что делает | Результат |
|---|---|---|
| **1. Сбор данных** | Скачивает реестр Рослесхоза (tochno.st) и тайлы MCD64A1 (NASA) | Ground Truth по региону |
| **2. Выравнивание** | Репроецирует всё в WGS84/UTM, применяет геодезические буферы 500 м | Единая система координат |
| **3. Детекция** | Сравнивает точки «Стрелы» с реестром пожаров | Precision / Recall / F1 |
| **4. Гари** | Сравнивает полигоны гарей (Sentinel-2 dNBR) с MCD64A1 | IoU, корреляция площадей |
| **5. Отчёт** | Генерирует Markdown-отчёт + интерактивную карту (Folium) | Артефакты для стейкхолдеров |

**Суть:** агент получает на вход регион и период → автоматически скачивает эталонные данные → прогоняет метрики → выдаёт готовый отчёт с цифрами и картой.

## 🗺️ Шаг 4. Определи тайлы для твоего региона

Данные MCD64A1 разбиты на **синусоидальные тайлы** (36×18, каждый ~1200×1200 км).

### Для Иркутской области / Якутии:

| Регион | Тайлы (примерно) |
|---|---|
| **Иркутская область** (97–119E, 51–60N) | `h21–h26 × v02–v04` — точный список выдаёт скрипт/CMR; г. Иркутск = `h24v03` |
| **Якутия (юг)** (Якутск) | `h23v02`, `h24v02` |
| **Московский регион** (Москва) | `h20v03` |

> ⚠️ Номера тайлов НЕ считаются по «наивной» формуле h=(λ+180)/10 — проверено по CMR
> (июль 2024): Москва=h20v03, Калининград=h19v03, Иркутск=h24v03. Не угадывайте тайлы —
> используйте программу ниже или `downnasagov.py` (ищет сами через CMR).

### Программа для точного определения тайла:

```python
from pyproj import Transformer
import math

def get_modis_tile(lat: float, lon: float) -> str:
    """Возвращает тайл синусоидальной сетки MODIS для координат."""
    # Переводим в синусоидальную проекцию
    transformer = Transformer.from_crs("EPSG:4326", "ESRI:54008", always_xy=True)
    x, y = transformer.transform(lon, lat)
    
    R = 6371007.2  # радиус Земли в синусоидальной проекции MODIS
    tile_size = 1111950.5197  # размер тайла в метрах
    
    h = int((x + 20015109.354) / tile_size)
    v = int((10007554.677 - y) / tile_size)
    
    return f"h{h:02d}v{v:02d}"

# Пример: центр Иркутской области (проверено по CMR, июль 2024)
print(get_modis_tile(52.3, 104.3))  # → h24v03
print(get_modis_tile(56.0, 106.0))  # → h24v03
```

### Визуальная проверка тайлов:
- Карта тайлов: **https://modis-land.gsfc.nasa.gov/pdf/MODIS_sinusoidal_tile_grid.pdf**
- Или интерактивно: **https://ladsweb.modaps.eosdis.nasa.gov/search/map/**

## 📥 Шаг 5. Скачивание данных

### Где теперь лежат файлы (обновлено 2026-10-20)

⚠️ Старые прямые URL вида `ladsweb.../archive/allData/61/MCD64A1/YYYY.DDD/`
**больше не работают (404)**. Данные теперь раздаёт LP DAAC:
`data.lpdaac.earthdatacloud.nasa.gov/lp-prod-protected/MCD64A1.061/<title>/<title>.hdf`,
а точное имя файла (с таймстампом выпуска) отдаёт CMR:
`https://cmr.earthdata.nasa.gov/search/granules.json?short_name=MCD64A1&point=lon,lat&temporal=...`.

Надёжный способ — скрипт (сам ищет тайлы в CMR и скачивает, с кэшем):
```bash
python validation/downnasagov.py --bbox 97,51,119,60 --year 2024 --month 7
```
- токен `EARTHDATA_TOKEN` берётся из `fire-monitor/.env`;
- вывод — `fire-monitor/data/mcd64a1/` (шарится с контейнерами через volume);
- пример имени файла: `MCD64A1.A2024183.h24v03.061.2024251154751.hdf`
  (1 июля 2024 в високосном году = **183-й** день года, а не 182-й).

### Вариант А: curl (ручное скачивание одного файла)

URL берётся из CMR (скрипт `downnasagov.py` делает это автоматически).
Ручная схема: запрос `granules.json?short_name=MCD64A1&point=...&temporal=...`
→ из ответа взять `href` ссылки `data#` (…`.hdf`) →
`curl -L -H "Authorization: Bearer $EARTHDATA_TOKEN" "<href>" -o file.hdf`
(`-L` обязательно: LP DAAC отвечает 303 на presigned CloudFront URL).

### Вариант Б: пакетное скачивание

Готовый скрипт **`validation/downnasagov.py`** (CMR-поиск тайлов + скачивание
с кэшем; работает с хоста, токеном из `fire-monitor/.env`):
```bash
python validation/downnasagov.py --bbox 97,51,119,60 --year 2024 --month 7
```
Старый `MCD64A1Downloader`-код на URL `ladsweb.../archive/allData/...` более
не работает (404) и здесь не дублируется.

### Вариант В: wget

Не нужен: `downnasagov.py` сам проходит редиректы (303 → presigned CloudFront URL).

```python
    scale=500,
    region=region,
    crs='EPSG:4326',
    fileFormat='GeoTIFF'
)
task.start()
```
